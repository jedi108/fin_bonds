# Команда: `analyze-buy-candidates`

## Описание
Команда для анализа облигаций, которых нет в портфеле, с целью поиска потенциальных покупок. Использует рыночные цены для расчета реальной доходности к погашению.

## Синтаксис
```bash
python3 main.py analyze-buy-candidates <режим> [опции]
```

## Режимы работы

### 1. `top` - Топ бумаг по доходности
Показывает облигации с наивысшей доходностью к погашению.

### 2. `floaters` - Флоатеры для покупки
Показывает облигации с плавающим купоном.

### 3. `compare` - Сравнение с портфелем
Сравнивает потенциальные покупки с текущим портфелем.

## Параметры

### Общие параметры для всех режимов

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `--limit` | integer | `10` | Количество облигаций для показа |
| `--min-risk` | integer | `2` | Максимальный уровень риска |
| `--min-months` | integer | `1` | Минимальное время до погашения (месяцы) |
| `--fixed-coupon` | flag | `false` | Только облигации с фиксированным купоном |
| `--floating-coupon` | flag | `false` | Только флоатеры |
| `--amortization` | flag | `false` | Только амортизируемые облигации |
| `--no-amortization` | flag | `false` | Исключить амортизируемые облигации |

### Детальное описание параметров

#### `--limit`
Количество облигаций для отображения в результатах.

**Диапазон:** 1-100
**Рекомендации:**
- Для быстрого анализа: 5-10
- Для детального анализа: 20-50
- Для полного обзора: 100

**Примеры:**
```bash
# Показать топ-5 облигаций
python3 main.py analyze-buy-candidates top --limit 5

# Показать топ-20 облигаций
python3 main.py analyze-buy-candidates top --limit 20
```

#### `--min-risk`
Максимальный уровень риска облигаций для анализа.

**Доступные значения:**
- `1` - Очень низкий риск (AAA, AA+)
- `2` - Низкий риск (AA, A+, A)
- `3` - Средний риск (A-, BBB+)
- `4` - Высокий риск (BBB, BB+)
- `5` - Очень высокий риск (BB и ниже)

**Рекомендации:**
- Консервативный подход: `--min-risk 1`
- Умеренный подход: `--min-risk 2`
- Агрессивный подход: `--min-risk 3`

**Примеры:**
```bash
# Только очень надежные облигации
python3 main.py analyze-buy-candidates top --min-risk 1

# Включая средний риск
python3 main.py analyze-buy-candidates top --min-risk 3
```

#### `--min-months`
Минимальное время до погашения в месяцах.

**Рекомендации:**
- Краткосрочные: `--min-months 1` (1-12 месяцев)
- Среднесрочные: `--min-months 12` (1-3 года)
- Долгосрочные: `--min-months 36` (3+ лет)

**Примеры:**
```bash
# Облигации с погашением через 1+ месяц
python3 main.py analyze-buy-candidates top --min-months 1

# Облигации с погашением через 1+ год
python3 main.py analyze-buy-candidates top --min-months 12
```

#### `--fixed-coupon`
Флаг для показа только облигаций с фиксированным купоном.

**Особенности:**
- Исключает флоатеры (облигации с плавающим купоном)
- Показывает облигации с постоянной ставкой купона
- Полезно для консервативных инвесторов

**Примеры:**
```bash
# Только облигации с фиксированным купоном
python3 main.py analyze-buy-candidates top --fixed-coupon

# Комбинированный фильтр
python3 main.py analyze-buy-candidates top --fixed-coupon --min-risk 2 --limit 10
```

#### `--floating-coupon`
Флаг для показа только флоатеров (облигаций с плавающим купоном).

**Особенности:**
- Исключает облигации с фиксированным купоном
- Показывает флоатеры с рассчитанной ставкой
- Полезно для анализа плавающих ставок

**Примеры:**
```bash
# Только флоатеры
python3 main.py analyze-buy-candidates top --floating-coupon

# Флоатеры с ограничениями
python3 main.py analyze-buy-candidates top --floating-coupon --min-risk 2 --limit 15
```

#### `--amortization`
Флаг для показа только амортизируемых облигаций.

**Особенности:**
- Показывает облигации с амортизацией долга
- Номинал облигации уменьшается со временем
- Полезно для анализа структурированных облигаций

**Примеры:**
```bash
# Только амортизируемые облигации
python3 main.py analyze-buy-candidates top --amortization

# Амортизируемые с ограничениями
python3 main.py analyze-buy-candidates top --amortization --min-risk 2 --limit 10
```

#### `--no-amortization`
Флаг для исключения амортизируемых облигаций.

**Особенности:**
- Исключает облигации с амортизацией долга
- Показывает только облигации с фиксированным номиналом
- Полезно для консервативных инвесторов

**Примеры:**
```bash
# Исключить амортизируемые облигации
python3 main.py analyze-buy-candidates top --no-amortization

# Комбинированный фильтр
python3 main.py analyze-buy-candidates top --fixed-coupon --no-amortization --min-risk 2
```

## Структура вывода

### Поля в таблице результатов

| Поле | Описание | Формат |
|------|----------|--------|
| `ISIN` | Международный идентификатор | 12 символов |
| `Тикер` | Биржевой тикер | 8 символов |
| `Название` | Название облигации | 25 символов |
| `Купон %` | Ставка купона | Процент |
| `Риск` | Уровень риска | 1-5 |
| `Цена` | Рыночная цена | Рубли |
| `Доходность %` | Доходность к погашению | Процент |
| `До погаш.` | Время до погашения | Месяцы |
| `Тип` | Тип облигации | Обычная/Флоатер/Амортизируемая |

### Типы облигаций
- **Обычная** - Фиксированная ставка купона
- **Флоатер** - Плавающая ставка купона
- **Амортизируемая** - С амортизацией долга

## Алгоритм анализа

### 1. Фильтрация облигаций
1. Исключает облигации из портфеля
2. Фильтрует по валюте (только RUB)
3. Фильтрует по уровню риска
4. Фильтрует по времени до погашения
5. Исключает бессрочные облигации

### 2. Расчет доходности
**Формула доходности к погашению:**
```
Доходность = (Годовой купонный доход / Рыночная цена) × 100%
```

**Где:**
- Годовой купонный доход = Ставка купона × Номинал / 100
- Рыночная цена = Цена из TBank API

### 3. Сортировка результатов
- **Режим `top`**: По убыванию доходности к погашению
- **Режим `floaters`**: По убыванию купонного дохода
- **Режим `compare`**: По разнице с портфелем

## Критерии отбора

### Базовые критерии
- ✅ Валюта: RUB
- ✅ Доступность для торговли: Да
- ✅ Не в портфеле
- ✅ Есть рыночная цена
- ✅ Есть ставка купона

### Дополнительные критерии
- ✅ Уровень риска ≤ указанного
- ✅ Время до погашения ≥ указанного
- ✅ Не бессрочная облигация

### Специальные критерии для флоатеров
- ✅ Флаг плавающего купона = 1
- ✅ Есть рассчитанная ставка купона
- ✅ Установлен спред (опционально)

## Интеграция с другими командами

### Зависимости
- `update-bonds` - для получения рыночных цен
- `sync-portfolio` - для определения облигаций в портфеле

### Использование результатов
Результаты можно использовать для:
- Ручного анализа в брокерском терминале
- Автоматической торговли (при интеграции)
- Планирования покупок

## Ограничения и особенности

### Требования к данным
- Рыночные цены должны быть актуальными (<24 часа)
- Портфель должен быть синхронизирован
- Каталог облигаций должен быть обновлен

### Ограничения API
- Зависит от доступности TBank API для цен
- Зависит от актуальности данных MOEX для купонов

### Производительность
- Время выполнения: <1 секунды
- Память: Минимальная
- Сеть: Не требуется (использует локальную БД)

## Устранение неполадок

### Проблема: Нет результатов
```bash
# Проверить наличие рыночных цен
sqlite3 ratings.db "SELECT COUNT(*) FROM bonds_catalog WHERE market_price IS NOT NULL;"

# Обновить цены
python3 main.py update-bonds --prices-only

# Проверить портфель
python3 main.py sync-portfolio
```

### Проблема: Нет флоатеров
```bash
# Проверить наличие флоатеров
sqlite3 ratings.db "SELECT COUNT(*) FROM bonds_catalog WHERE floating_coupon_flag = 1;"

# Обновить данные с MOEX
python3 main.py update-bonds --source moex
```

### Проблема: Низкая доходность
```bash
# Увеличить уровень риска
python3 main.py analyze-buy-candidates top --min-risk 3

# Увеличить лимит результатов
python3 main.py analyze-buy-candidates top --limit 50
```
