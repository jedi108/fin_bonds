# Команда: `check-changes`

## Описание
Команда для проверки изменений в портфеле облигаций. Отслеживает изменения цен, рейтингов, уровней риска и других метрик, отправляя уведомления о значимых изменениях.

## Синтаксис
```bash
python3 main.py check-changes [опции]
```

## Параметры

### Основные параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `--days` | integer | `1` | Количество дней для проверки изменений |
| `--min-change` | float | `5.0` | Минимальное изменение цены в процентах для уведомления |
| `--notify` | flag | `true` | Отправлять уведомления |

### Детальное описание параметров

#### `--days`
Количество дней назад для проверки изменений.

**Диапазон:** 1-30 дней
**Рекомендации:**
- Ежедневная проверка: `--days 1`
- Еженедельная проверка: `--days 7`
- Месячная проверка: `--days 30`

**Примеры:**
```bash
# Проверить изменения за последний день
python3 main.py check-changes --days 1

# Проверить изменения за неделю
python3 main.py check-changes --days 7
```

#### `--min-change`
Минимальное изменение цены в процентах для отправки уведомления.

**Диапазон:** 0.1-50.0%
**Рекомендации:**
- Консервативный подход: `--min-change 2.0`
- Умеренный подход: `--min-change 5.0`
- Агрессивный подход: `--min-change 10.0`

**Примеры:**
```bash
# Уведомления при изменении цены более 2%
python3 main.py check-changes --min-change 2.0

# Уведомления при изменении цены более 10%
python3 main.py check-changes --min-change 10.0
```

#### `--notify`
Флаг для включения/отключения отправки уведомлений.

**Примеры:**
```bash
# Проверить изменения без уведомлений
python3 main.py check-changes --notify false

# Проверить изменения с уведомлениями (по умолчанию)
python3 main.py check-changes --notify true
```

## Примеры использования

### 1. Ежедневная проверка изменений
```bash
python3 main.py check-changes --days 1 --min-change 5.0
```
**Что происходит:**
- Проверяет изменения за последний день
- Уведомляет об изменениях цены более 5%
- Отправляет уведомления в Telegram

### 2. Еженедельная проверка без уведомлений
```bash
python3 main.py check-changes --days 7 --notify false
```
**Что происходит:**
- Проверяет изменения за неделю
- Выводит отчет в консоль
- Не отправляет уведомления

### 3. Консервативная проверка
```bash
python3 main.py check-changes --days 1 --min-change 2.0
```
**Что происходит:**
- Проверяет изменения за день
- Уведомляет об изменениях более 2%
- Более чувствительная настройка

## Структура данных

### Проверяемые изменения

| Метрика | Источник | Тип изменения | Уведомление |
|---------|----------|---------------|-------------|
| Цена облигации | `portfolio_positions` | Процентное изменение | При превышении порога |
| Кредитный рейтинг | `monitoring_checks` | Изменение уровня | Всегда |
| Уровень риска | `monitoring_checks` | Изменение уровня | Всегда |
| Уровень листинга | `monitoring_checks` | Изменение уровня | Всегда |
| Ставка купона | `monitoring_checks` | Изменение процента | При значительном изменении |

## Алгоритм работы

### 1. Получение данных портфеля
1. Загружает текущие позиции из `portfolio_positions`
2. Получает исторические данные за указанный период
3. Загружает метрики из `monitoring_checks`

### 2. Анализ изменений
1. Сравнивает текущие и исторические цены
2. Проверяет изменения рейтингов и рисков
3. Вычисляет процентные изменения
4. Фильтрует по минимальному порогу

### 3. Формирование отчета
1. Группирует изменения по типам
2. Сортирует по значимости
3. Формирует текст уведомлений
4. Подготавливает консольный вывод

### 4. Отправка уведомлений
1. Проверяет настройки уведомлений
2. Отправляет в Telegram (если включено)
3. Выводит отчет в консоль

## Ограничения и особенности

### Требования к данным
- Портфель должен быть синхронизирован
- Исторические данные должны быть доступны
- Метрики должны быть обновлены

### Ограничения API
- Зависит от доступности Telegram API
- Ограничения на размер уведомлений
- Частота отправки уведомлений

### Производительность
- Время выполнения: ~30 секунд
- Память: Минимальная
- Сеть: Только для уведомлений

## Интеграция с другими командами

### Зависимости
- `sync-portfolio` - для актуальных данных портфеля
- `update-ratings` - для метрик мониторинга
- `update-bonds` - для рыночных цен

### Использование результатов
Результаты используются для:
- Мониторинга портфеля
- Принятия решений о покупке/продаже
- Отслеживания рисков

## Мониторинг и логирование

### Уровни логирования
- `INFO` - Основные этапы проверки
- `DEBUG` - Детальная информация об изменениях
- `WARNING` - Проблемы с отдельными облигациями
- `ERROR` - Критические ошибки

### Ключевые метрики
- Количество проверенных облигаций
- Количество найденных изменений
- Количество отправленных уведомлений
- Время выполнения проверки

## Устранение неполадок

### Проблема: Нет уведомлений
```bash
# Проверить настройки Telegram
cat config/config.yaml | grep telegram

# Проверить переменные окружения
echo $TELEGRAM_BOT_TOKEN
echo $TELEGRAM_CHAT_ID

# Проверить логи
python3 main.py check-changes --verbose
```

### Проблема: Нет данных для сравнения
```bash
# Проверить наличие исторических данных
sqlite3 ratings.db "SELECT COUNT(*) FROM monitoring_checks;"

# Обновить данные
python3 main.py update-ratings
python3 main.py sync-portfolio
```

### Проблема: Много ложных срабатываний
```bash
# Увеличить порог изменения
python3 main.py check-changes --min-change 10.0

# Проверить за больший период
python3 main.py check-changes --days 7
```

### Проблема: Нет изменений в отчете
```bash
# Проверить данные портфеля
sqlite3 ratings.db "SELECT COUNT(*) FROM portfolio_positions;"

# Проверить метрики
sqlite3 ratings.db "SELECT COUNT(*) FROM monitoring_checks WHERE check_date >= date('now', '-1 day');"
```

## Рекомендации по использованию

### Регулярная проверка
```bash
# Ежедневная проверка (утром)
python3 main.py check-changes --days 1 --min-change 5.0

# Еженедельная проверка (пятница)
python3 main.py check-changes --days 7 --min-change 10.0
```

### Автоматизация
```bash
# Добавить в crontab для ежедневной проверки в 9:00
0 9 * * * cd /path/to/portfolio && python3 main.py check-changes --days 1

# Добавить в crontab для еженедельной проверки в пятницу 18:00
0 18 * * 5 cd /path/to/portfolio && python3 main.py check-changes --days 7
```

### Настройка уведомлений
```bash
# Консервативные настройки
python3 main.py check-changes --min-change 2.0 --days 1

# Умеренные настройки
python3 main.py check-changes --min-change 5.0 --days 1

# Агрессивные настройки
python3 main.py check-changes --min-change 10.0 --days 1
```

### Тестирование без уведомлений
```bash
# Проверить логику без отправки уведомлений
python3 main.py check-changes --notify false --verbose

# Проверить за больший период
python3 main.py check-changes --days 30 --notify false
```
