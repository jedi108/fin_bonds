# Команда: `calculate-ytm`

## Описание
Команда для расчета доходности к погашению (Yield to Maturity, YTM) облигаций. Поддерживает расчет для облигаций в портфеле и потенциальных покупок, включая облигации с фиксированным и плавающим купоном.

## Синтаксис
```bash
python3 main.py calculate-ytm [опции]
```

## Параметры

### Основные параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `--mode` | string | `portfolio` | Режим расчета YTM |
| `--limit` | integer | `10` | Количество облигаций для показа |
| `--max-risk` | integer | `5` | Максимальный уровень риска |
| `--min-maturity` | string | - | Минимальная дата погашения |
| `--fixed-coupon` | flag | `false` | Только облигации с фиксированным купоном |
| `--floating-coupon` | flag | `false` | Только флоатеры |

### Детальное описание параметров

#### `--mode`
Режим расчета доходности к погашению.

**Доступные значения:**
- `portfolio` - Облигации в портфеле (по умолчанию)
- `buy` - Потенциальные покупки

**Примеры:**
```bash
# Расчет YTM для портфеля
python3 main.py calculate-ytm --mode portfolio

# Расчет YTM для потенциальных покупок
python3 main.py calculate-ytm --mode buy
```

#### `--limit`
Количество облигаций для отображения в результатах.

**Диапазон:** 1-100
**Рекомендации:**
- Для быстрого анализа: 5-10
- Для детального анализа: 20-50
- Для полного обзора: 100

**Примеры:**
```bash
# Показать топ-5 облигаций
python3 main.py calculate-ytm --limit 5

# Показать топ-20 облигаций
python3 main.py calculate-ytm --limit 20
```

#### `--max-risk`
Максимальный уровень риска облигаций для анализа.

**Доступные значения:**
- `1` - Очень низкий риск (AAA, AA+)
- `2` - Низкий риск (AA, A+, A)
- `3` - Средний риск (A-, BBB+)
- `4` - Высокий риск (BBB, BB+)
- `5` - Очень высокий риск (BB и ниже)

**Примеры:**
```bash
# Только очень надежные облигации
python3 main.py calculate-ytm --max-risk 1

# Включая средний риск
python3 main.py calculate-ytm --max-risk 3
```

#### `--min-maturity`
Минимальная дата погашения для фильтрации облигаций.

**Формат:** YYYY-MM-DD
**Примеры:**
```bash
# Облигации с погашением после 2025 года
python3 main.py calculate-ytm --min-maturity 2025-01-01

# Облигации с погашением после 2027 года
python3 main.py calculate-ytm --min-maturity 2027-01-01
```

#### `--fixed-coupon`
Флаг для показа только облигаций с фиксированным купоном.

**Примеры:**
```bash
# Только облигации с фиксированным купоном
python3 main.py calculate-ytm --fixed-coupon

# Комбинированный фильтр
python3 main.py calculate-ytm --mode buy --fixed-coupon --max-risk 2
```

#### `--floating-coupon`
Флаг для показа только флоатеров (облигаций с плавающим купоном).

**Примеры:**
```bash
# Только флоатеры
python3 main.py calculate-ytm --floating-coupon

# Флоатеры для покупки
python3 main.py calculate-ytm --mode buy --floating-coupon
```

## Структура данных

### Поля в таблице результатов

| Поле | Описание | Формат |
|------|----------|--------|
| `ISIN` | Международный идентификатор | 12 символов |
| `Название` | Название облигации | 25 символов |
| `Купон %` | Ставка купона | Процент |
| `Цена` | Текущая цена | Рубли |
| `YTM %` | Доходность к погашению | Процент |
| `До погаш.` | Время до погашения | Месяцы |
| `Риск` | Уровень риска | 1-5 |
| `Тип` | Тип облигации | Обычная/Флоатер/Амортизируемая |

### Расчет YTM

#### Формула для облигаций с фиксированным купоном
```
YTM = (Годовой купонный доход / Текущая цена) × 100%
```

#### Формула для флоатеров
```
YTM = (Рассчитанная ставка купона × Номинал / 100 / Текущая цена) × 100%
```

**Где:**
- Годовой купонный доход = Ставка купона × Номинал / 100
- Рассчитанная ставка = RUONIA + Спред
- Текущая цена = Цена из портфеля или рыночная цена

## Алгоритм работы

### 1. Фильтрация облигаций
1. Выбирает облигации по режиму (портфель/покупки)
2. Фильтрует по уровню риска
3. Фильтрует по дате погашения
4. Фильтрует по типу купона (фиксированный/плавающий)

### 2. Расчет доходности
1. Получает данные об облигациях
2. Рассчитывает YTM по соответствующей формуле
3. Обрабатывает флоатеры с учетом спреда
4. Валидирует результаты

### 3. Сортировка и вывод
1. Сортирует по доходности (убывание)
2. Ограничивает количество результатов
3. Форматирует вывод в таблицу

## Ограничения и особенности

### Требования к данным
- Портфель должен быть синхронизирован (для режима portfolio)
- Рыночные цены должны быть актуальными (для режима buy)
- Данные о спредах должны быть установлены (для флоатеров)

### Ограничения расчета
- Упрощенная формула YTM (без учета реинвестирования)
- Не учитывает налоги и комиссии
- Для флоатеров используется текущая ставка RUONIA

### Производительность
- Время выполнения: <1 секунды
- Память: Минимальная
- Сеть: Не требуется (использует локальную БД)

## Интеграция с другими командами

- `sync-portfolio` - для данных портфеля

### Использование результатов
Результаты используются для:
- Анализа доходности портфеля
- Сравнения с альтернативными инвестициями
- Принятия решений о покупке/продаже

## Мониторинг и логирование

### Уровни логирования
- `INFO` - Основные этапы расчета
- `DEBUG` - Детальная информация о расчетах
- `WARNING` - Проблемы с отдельными облигациями
- `ERROR` - Критические ошибки

### Ключевые метрики
- Количество обработанных облигаций

- Время выполнения расчета

## Устранение неполадок

### Проблема: Нет данных портфеля
```bash
# Проверить наличие позиций в портфеле
sqlite3 ratings.db "SELECT COUNT(*) FROM portfolio_positions;"

# Синхронизировать портфель
python3 main.py sync-portfolio
```

### Проблема: Нет рыночных цен
```bash
# Проверить наличие рыночных цен
sqlite3 ratings.db "SELECT COUNT(*) FROM bonds_catalog WHERE market_price IS NOT NULL;"

# Обновить рыночные цены
python3 main.py update-bonds --prices-only
```

### Проблема: Нет спредов для флоатеров
```bash
# Проверить наличие спредов
sqlite3 ratings.db "SELECT COUNT(*) FROM bonds_catalog WHERE coupon_spread IS NOT NULL;"

# Установить спреды
python3 main.py set-spread --all --default-spread 2.0
```

### Проблема: Некорректные расчеты
```bash
# Проверить данные облигации
sqlite3 ratings.db "SELECT * FROM bonds_catalog WHERE isin = 'RU000A1084K3';"

# Проверить позицию в портфеле
sqlite3 ratings.db "SELECT * FROM portfolio_positions WHERE isin = 'RU000A1084K3';"
```
