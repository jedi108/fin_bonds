## Быстрый старт

### 🚀 Основные команды для начала работы

1. **Обновление данных:**
   ```bash
   # Обновить каталог облигаций и цены
   python3 main.py update-bonds --update-prices
   
   # Синхронизировать портфель
   python3 main.py sync-portfolio
   ```

2. **Анализ потенциальных покупок:**
   ```bash
   # Топ облигаций по доходности
   python3 main.py analyze-buy-candidates top --limit 10
   
   # Флоатеры для покупки
   python3 main.py analyze-buy-candidates floaters --limit 5
   ```

3. **Мониторинг портфеля:**
   ```bash
   # Проверить изменения
   python3 main.py check-changes
   
   # Проверить оферты
   python3 main.py check-offers
   ```

### 📊 Регулярные задачи

#### Ежедневно
```bash
# Обновить цены
python3 main.py update-bonds --prices-only

# Проверить изменения
python3 main.py check-changes
```

#### Еженедельно
```bash
# Полное обновление данных
python3 main.py update-bonds --update-prices

# Обновить рейтинги
python3 main.py update-ratings

# Проверить оферты
python3 main.py check-offers
```

#### Ежемесячно
```bash
# Экспорт портфеля
python3 main.py export-portfolio --format xlsx

# Генерация графиков
python3 main.py generate-plots
```

## Автоматизация

### 🕐 Cron задачи

Система поддерживает автоматическое выполнение через `run_update.sh`:

```bash
# Добавить в crontab для ежедневного выполнения в 9:00
0 9 * * * /path/to/portfolio/run_update.sh
```

### 📧 Уведомления

Команды мониторинга могут отправлять уведомления при обнаружении изменений:
- Падение рейтинга
- Изменение уровня риска
- Приближающиеся оферты
- Значительные изменения цен

## Конфигурация

### ⚙️ Основные настройки

Файл `config/config.yaml` содержит:
- Пути к базе данных
- Настройки API
- Параметры мониторинга
- Шкала рейтингов

### 🔑 API токены

Требуемые переменные окружения:
- `TBANK_TOKEN` - токен для TBank API
- `MOEX_TOKEN` - токен для MOEX API (опционально)
- `ALOR_TOKEN` - токен для Alor API (опционально)
