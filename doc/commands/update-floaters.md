# Команда `update-floaters`

## 1. Описание

Команда `update-floaters` предназначена для обновления процентной ставки купона (`coupon_rate_percent`) в основной таблице `bonds_catalog` для всех облигаций с плавающим купоном (флоатеров).

Это позволяет поддерживать актуальность данных о купонах, так как их ставка зависит от изменяемых внешних индикаторов, таких как ставка RUONIA. Актуальное значение купона критически важно для корректного расчета доходности к погашению (YTM) и других аналитических метрик.

## 2. Синтаксис

Команда запускается без дополнительных аргументов:

```bash
python main.py update-floaters
```

## 3. Алгоритм работы

1.  **Автоматический расчет спредов (Новое в последней версии)**: Перед основным обновлением, команда автоматически запускает логику, аналогичную `calculate-spread`, для всех флоатеров в портфеле, у которых спред еще не задан. Это позволяет уменьшить количество ручных действий.
2.  **Получение базовой ставки**: Скрипт запрашивает последнее доступное значение ставки RUONIA через API Центрального Банка РФ.
3.  **Выборка флоатеров**: Из базы данных выбираются все облигации, которые являются флоатерами (`floating_coupon_flag = 1`) и одновременно **присутствуют в портфеле** (`portfolio_positions`).
4.  **Расчет нового купона**: Для каждой облигации-флоатера, у которой в базе задан спред (включая только что рассчитанные), вычисляется новая ставка по формуле:
    ```
    Новая ставка = (Ставка RUONIA) + (Спред облигации)
    ```
5.  **Обновление базы данных**: Поле `coupon_rate_percent` в таблице `bonds_catalog` обновляется новым рассчитанным значением.

> **Важно:** Если для облигации-флоатера не указан спред, ее ставка не будет обновлена. В логах появится предупреждение. О том, как управлять спредами, читайте ниже.

## 4. Управление спредами для флоатеров

Спред — это фиксированная надбавка к плавающей ставке (RUONIA), которая определяет итоговый купон облигации. Его необходимо задать для каждой облигации-флоатера, чтобы команда `update-floaters` могла корректно работать.

Существует два способа управления спредами:

### 4.1. Автоматический расчет (`calculate-spread`)

Система может попытаться рассчитать спред автоматически на основе истории купонных выплат.

**Синтаксис:**

```bash
# Рассчитать спреды для всех флоатеров в портфеле, у которых он еще не задан
python main.py calculate-spread

# Рассчитать спред для конкретной облигации по тикеру
python main.py calculate-spread --ticker <TICKER>
```

**Как это работает:**
- Скрипт получает историю купонных выплат по облигации (через Tinkoff API).
- Находит последнюю выплату и рассчитывает ее годовую процентную ставку.
- Получает историческое значение ставки RUONIA на дату начала того купонного периода.
- Вычисляет разницу (спред) и сохраняет ее в базу данных.

**Ограничения:**
- Метод работает только для облигаций, по которым уже была хотя бы одна выплата купона.
- Требуется доступ к Tinkoff API.
- Если эмитент меняет спред (например, в дату оферты), автоматический расчет сможет определить новый спред только **после** первой выплаты по новым условиям.

### 4.2. Ручная установка (`set-spread`)

Если вы знаете спред для облигации (например, из ее эмиссионной документации), вы можете установить его вручную.

**Синтаксис:**

```bash
python main.py set-spread --isin <ISIN> --spread <ЗНАЧЕНИЕ>
```

**Параметры:**
- `--isin`: ISIN-код облигации.
- `--spread`: Значение спреда в процентах (например, `1.5` для 1.5%).

**Пример:**

```bash
python main.py set-spread --isin RU000A108GS4 --spread 1.9
```

Этот способ является наиболее надежным и рекомендуется, если автоматический расчет невозможен или вы хотите задать точное значение.

## 5. Интеграция

Команда `update-floaters` является частью регулярного процесса обновления данных. Рекомендуется запускать ее после `update-bonds` и `sync-portfolio`, чтобы обеспечить актуальность всех связанных данных.
