# Команда: `update-bonds`

## Описание
Команда для обновления каталога облигаций и рыночных цен. Получает данные из TBank API и MOEX API, обогащает их и сохраняет в локальную базу данных.

## Синтаксис
```bash
python3 main.py update-bonds [опции]
```

## Параметры

### Основные параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `--output` | string | `none` | Формат вывода данных |
| `--source` | string | `all` | Источник данных для обновления |
| `--update-prices` | flag | `false` | Обновить рыночные цены для облигаций |
| `--prices-only` | flag | `false` | Обновить только рыночные цены, без обновления каталога |

### Детальное описание параметров

#### `--output`
Формат вывода данных о каталоге облигаций.

**Доступные значения:**
- `none` - Без вывода (по умолчанию)
- `csv` - Сохранить в CSV файл
- `gsheets` - Экспорт в Google Sheets
- `console` - Вывод в консоль

**Примеры:**
```bash
# Вывод в консоль
python3 main.py update-bonds --output console

# Сохранение в CSV
python3 main.py update-bonds --output csv
```

#### `--source`
Источник данных для обновления каталога.

**Доступные значения:**
- `all` - Все источники (по умолчанию)
- `tbank` - Только TBank API
- `moex` - Только MOEX API

**Примеры:**
```bash
# Обновить только из TBank
python3 main.py update-bonds --source tbank

# Обновить только из MOEX
python3 main.py update-bonds --source moex
```

#### `--update-prices`
Флаг для обновления рыночных цен облигаций в каталоге.

**Особенности:**
- Получает цены через TBank API
- Обновляет только облигации без цен или с устаревшими ценами (>24 часа)
- Конвертирует цены из процентов в абсолютные значения
- Сохраняет источник цены (`tbank`, `moex`, `alor`)

**Пример:**
```bash
# Обновить каталог и цены
python3 main.py update-bonds --update-prices
```

#### `--prices-only`
Флаг для обновления только рыночных цен без обновления каталога.

**Особенности:**
- Пропускает обновление каталога облигаций
- Обновляет только рыночные цены
- Полезно для частого обновления цен

**Пример:**
```bash
# Обновить только цены
python3 main.py update-bonds --prices-only
```

## Примеры использования

### 1. Полное обновление каталога и цен
```bash
python3 main.py update-bonds --update-prices
```
**Что происходит:**
- Получает все облигации из TBank API
- Добавляет новые облигации в каталог
- Обновляет данные с MOEX (листинг, купоны)
- Получает рыночные цены для всех облигаций

### 2. Обновление только цен
```bash
python3 main.py update-bonds --prices-only
```
**Что происходит:**
- Пропускает обновление каталога
- Обновляет только рыночные цены
- Быстрое выполнение (~1 минута)

### 3. Обновление с выводом в консоль
```bash
python3 main.py update-bonds --update-prices --output console
```
**Что происходит:**
- Обновляет каталог и цены
- Выводит список облигаций в консоль

### 4. Обновление только из TBank
```bash
python3 main.py update-bonds --source tbank --update-prices
```
**Что происходит:**
- Обновляет каталог только из TBank API
- Пропускает обновление данных с MOEX
- Обновляет рыночные цены

## Структура данных

### Поля облигации в каталоге
| Поле | Тип | Источник | Описание |
|------|-----|----------|----------|
| `isin` | TEXT | TBank | Международный идентификатор |
| `figi` | TEXT | TBank | Уникальный идентификатор FIGI |
| `ticker` | TEXT | TBank | Биржевой тикер |
| `name` | TEXT | TBank | Название облигации |
| `currency` | TEXT | TBank | Валюта номинала |
| `nominal` | REAL | TBank | Номинальная стоимость |
| `maturity_date` | TEXT | TBank | Дата погашения |
| `coupon_rate_percent` | REAL | MOEX | Ставка купона |
| `risk_level` | INTEGER | TBank | Уровень риска |
| `is_trade_available` | INTEGER | TBank | Доступность для торговли |
| `market_price` | REAL | TBank | Рыночная цена |
| `market_price_source` | TEXT | TBank | Источник цены |
| `market_price_updated_at` | TEXT | TBank | Время обновления цены |

### Рыночные цены
Рыночные цены получаются через TBank API и сохраняются в абсолютных значениях (рубли).

**Формула конвертации:**
```
абсолютная_цена = цена_в_процентах × номинал / 100
```

**Пример:**
- Номинал: 1000 рублей
- Цена в API: 95.5% (0.955)
- Абсолютная цена: 955 рублей

## Логика работы

### 1. Обновление каталога из TBank
1. Получает все облигации из TBank API
2. Фильтрует только рублевые облигации
3. Определяет новые облигации для добавления
4. Добавляет/обновляет облигации в каталоге

### 2. Обновление данных с MOEX
1. Находит облигации для обновления (флоатеры, без листинга, без купонов)
2. Получает данные с MOEX API
3. Обновляет уровень листинга, ставку купона, дату оферты

### 3. Обновление рыночных цен
1. Находит облигации без цен или с устаревшими ценами
2. Получает FIGI для облигаций
3. Запрашивает цены через TBank API
4. Конвертирует цены в абсолютные значения
5. Сохраняет цены в базу данных

## Ограничения и особенности

### API лимиты
- TBank API: ~1000 запросов в минуту
- MOEX API: ~10 запросов в секунду

### Время выполнения
- Полное обновление: ~5-10 минут
- Только цены: ~1 минута
- Только MOEX: ~3-5 минут

### Обработка ошибок
- При ошибке TBank API: прерывание обновления
- При ошибке MOEX API: пропуск облигации, продолжение
- При ошибке получения цен: пропуск облигации, продолжение

## Интеграция с другими командами

### Автоматическое обновление
Команда интегрирована в `run_update.sh` для автоматического обновления:
```bash
python main.py update-bonds --update-prices
```

### Использование в анализе
Обновленные данные используются в командах:
- `analyze-buy-candidates` - анализ потенциальных покупок
- `calculate-ytm` - расчет доходности к погашению
- `export-bonds` - экспорт каталога

## Мониторинг и логирование

### Уровни логирования
- `INFO` - Основные этапы обновления
- `DEBUG` - Детальная информация о запросах
- `WARNING` - Проблемы с отдельными облигациями
- `ERROR` - Критические ошибки

### Ключевые метрики
- Количество загруженных облигаций
- Количество новых облигаций
- Количество обновленных цен
- Время выполнения каждого этапа

## Устранение неполадок

### Проблема: Пустая база данных
```bash
# Проверить конфигурацию
cat config/config.yaml

# Принудительно создать таблицы
python3 main.py update-bonds --update-prices
```

### Проблема: Ошибки API
```bash
# Проверить токены
echo $TBANK_TOKEN

# Обновить только каталог
python3 main.py update-bonds --source tbank
```

### Проблема: Нет рыночных цен
```bash
# Проверить доступность TBank API
python3 main.py update-bonds --prices-only

# Проверить данные в БД
sqlite3 ratings.db "SELECT COUNT(*) FROM bonds_catalog WHERE market_price IS NOT NULL;"
```
