# Команда: `sync-portfolio`

## Описание
Команда для синхронизации портфеля облигаций из различных источников: TBank API, Alor API или Excel-файлов. Загружает текущие позиции в портфеле и сохраняет их в локальную базу данных.

## Синтаксис
```bash
python3 main.py sync-portfolio [опции]
```

## Параметры

### Основные параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `--source` | string | `tbank` | Источник данных портфеля |
| `--excel-path` | string | - | Путь к Excel файлу (для source=excel) |

### Детальное описание параметров

#### `--source`
Источник данных для синхронизации портфеля.

**Доступные значения:**
- `tbank` - TBank API (по умолчанию)
- `alor` - Alor API
- `excel` - Excel файл
- `all` - Все доступные источники

**Примеры:**
```bash
# Синхронизация из TBank
python3 main.py sync-portfolio --source tbank

# Синхронизация из Alor
python3 main.py sync-portfolio --source alor

# Синхронизация из Excel файла
python3 main.py sync-portfolio --source excel --excel-path data/portfolio.xlsx

# Синхронизация из всех источников
python3 main.py sync-portfolio --source all
```

#### `--excel-path`
Путь к Excel файлу с данными портфеля. Используется только при `--source excel`.

**Формат Excel файла:**
- Колонка `ISIN` - международный идентификатор облигации
- Колонка `Quantity` - количество облигаций
- Колонка `Average Price` - средняя цена покупки
- Колонка `Current Price` - текущая цена (опционально)

**Пример:**
```bash
python3 main.py sync-portfolio --source excel --excel-path /path/to/portfolio.xlsx
```

## Примеры использования

### 1. Синхронизация из TBank API
```bash
python3 main.py sync-portfolio --source tbank
```
**Что происходит:**
- Подключается к TBank API
- Получает текущие позиции в портфеле
- Обновляет таблицу `portfolio_positions`
- Выводит статистику синхронизации

### 2. Синхронизация из Alor API
```bash
python3 main.py sync-portfolio --source alor
```
**Что происходит:**
- Подключается к Alor API
- Получает позиции из Alor
- Синхронизирует с локальной БД
- Показывает различия между источниками

### 3. Синхронизация из Excel файла
```bash
python3 main.py sync-portfolio --source excel --excel-path data/portfolio.xlsx
```
**Что происходит:**
- Читает Excel файл
- Парсит данные портфеля
- Обновляет локальную БД
- Валидирует данные

### 4. Синхронизация из всех источников
```bash
python3 main.py sync-portfolio --source all
```
**Что происходит:**
- Синхронизирует из TBank
- Синхронизирует из Alor (если доступен)
- Сравнивает данные между источниками
- Показывает различия

## Структура данных

### Поля в таблице `portfolio_positions`

| Поле | Тип | Источник | Описание |
|------|-----|----------|----------|
| `isin` | TEXT | API/Excel | Международный идентификатор |
| `broker_name` | TEXT | Код | Название брокера |
| `quantity` | REAL | API/Excel | Количество облигаций |
| `average_price` | REAL | API/Excel | Средняя цена покупки |
| `current_price` | REAL | API | Текущая рыночная цена |
| `currency` | TEXT | API | Валюта позиции |
| `yield_to_maturity` | REAL | API | Доходность к погашению |

### Форматы данных

#### TBank API
- Цены в абсолютных значениях (рубли)
- Количество в штуках
- Доходность в процентах

#### Alor API
- Цены в абсолютных значениях (рубли)
- Количество в штуках
- Дополнительные метаданные

#### Excel файл
- Поддерживает различные форматы
- Автоматическое определение колонок
- Валидация данных

## Логика работы

### 1. Подключение к источнику
1. Проверяет доступность API/файла
2. Валидирует токены доступа
3. Устанавливает соединение

### 2. Получение данных
1. Запрашивает текущие позиции
2. Парсит ответ API/файл
3. Нормализует данные

### 3. Обновление базы данных
1. Очищает старые данные портфеля
2. Вставляет новые позиции
3. Обновляет метаданные

### 4. Валидация и отчет
1. Проверяет корректность данных
2. Сравнивает с предыдущим состоянием
3. Выводит статистику изменений

## Ограничения и особенности

### API лимиты
- TBank API: ~1000 запросов в минуту
- Alor API: ~100 запросов в минуту

### Время выполнения
- TBank: ~30 секунд
- Alor: ~1-2 минуты
- Excel: ~10 секунд

### Обработка ошибок
- При ошибке API: прерывание синхронизации
- При ошибке файла: показ деталей ошибки
- При неполных данных: предупреждения

## Интеграция с другими командами

- `update-bonds` - для получения данных об облигациях
- `check-changes` - для отслеживания изменений

### Использование результатов

- `calculate-ytm` - расчет доходности

## Мониторинг и логирование

### Уровни логирования
- `INFO` - Основные этапы синхронизации
- `DEBUG` - Детальная информация о запросах
- `WARNING` - Проблемы с отдельными позициями
- `ERROR` - Критические ошибки

### Ключевые метрики
- Количество позиций в портфеле
- Количество новых позиций
- Количество удаленных позиций
- Время выполнения синхронизации

## Устранение неполадок

### Проблема: Ошибка подключения к API
```bash
# Проверить токены
echo $INVEST_TOKEN
echo $ALOR_TOKEN

# Проверить доступность API
python3 main.py test-tbank
python3 main.py test-alor
```

### Проблема: Пустой портфель
```bash
# Проверить данные в БД
sqlite3 ratings.db "SELECT COUNT(*) FROM portfolio_positions;"

# Проверить логи синхронизации
python3 main.py sync-portfolio --source tbank --verbose
```

### Проблема: Ошибка Excel файла
```bash
# Проверить формат файла
python3 main.py sync-portfolio --source excel --excel-path data/portfolio.xlsx --verbose

# Проверить структуру файла
head -5 data/portfolio.xlsx
```

### Проблема: Несоответствие данных
```bash
# Синхронизировать из всех источников для сравнения
python3 main.py sync-portfolio --source all

# Проверить различия в данных
sqlite3 ratings.db "SELECT * FROM portfolio_positions ORDER BY isin;"
```

## Рекомендации по использованию

### Регулярная синхронизация
```bash
# Ежедневная синхронизация
python3 main.py sync-portfolio --source tbank

# Еженедельная полная синхронизация
python3 main.py sync-portfolio --source all
```

### Автоматизация
```bash
# Добавить в crontab для ежедневной синхронизации
0 9 * * * cd /path/to/portfolio && python3 main.py sync-portfolio --source tbank
```

### Резервное копирование
```bash
# Экспорт портфеля перед синхронизацией
python3 main.py export-portfolio --format xlsx --output portfolio_backup.xlsx

# Синхронизация
python3 main.py sync-portfolio --source tbank
```
