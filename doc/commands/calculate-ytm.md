# Команда: `calculate-ytm`

## Описание
Команда для расчета и отображения доходности к погашению (Yield to Maturity, YTM) облигаций.
Использует единый канонический cashflow-решатель дисконтирования денежных потоков по чистой рыночной цене (`market_price`).

## Синтаксис
```bash
python3 main.py calculate-ytm [опции]
```

## Параметры

### Основные параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `--mode` | string | обязательный | Режим расчета: `buy` (кандидаты) или `portfolio` (позиции) |
| `--min-ytm` | float | `None` | Минимальная YTM для фильтрации (в процентах, например `15.0`) |
| `--limit` | integer | `50` | Количество облигаций для показа |
| `--max-risk` | integer | `3` | Максимальный уровень риска (1-5) |
| `--min-maturity` | string | `2025-01-01` | Минимальная дата погашения (YYYY-MM-DD) |
| `--max-maturity` | string | `2030-12-31` | Максимальная дата погашения (YYYY-MM-DD) |
| `--no-amortization` | flag | `false` | Исключить облигации с амортизацией |
| `--monthly-coupons` | flag | `false` | Только облигации с ежемесячными купонами (12 раз в год) |
| `--fixed-coupon` | flag | `false` | Только облигации с фиксированным купоном |
| `--floating-coupon` | flag | `false` | Только флоатеры |

### Детальное описание параметров

#### `--mode`
Режим расчета доходности к погашению:
- `buy` — облигации вне портфеля по текущей чистой рыночной цене `market_price`.
- `portfolio` — позиции портфеля. YTM также рассчитывается mark-to-market по рыночной цене `market_price`, а средняя цена покупки позиции (`average_price`) выводится как справочная колонка и не подменяет YTM.

#### `--min-ytm`
Фильтрация по минимальной годовой доходности к погашению в процентах.
При указании порога отсекаются бумаги с меньшей YTM, а также бумаги с намеренным `NULL` (порог не превращает `NULL` в 0).

## Примеры использования

### 1. Расчет YTM для портфеля
```bash
python3 main.py calculate-ytm --mode portfolio --limit 10
```

### 2. Анализ потенциальных покупок
```bash
python3 main.py calculate-ytm --mode buy --fixed-coupon --min-ytm 15.0 --limit 15
```

### 3. Анализ с фильтрацией по риску и сроку
```bash
python3 main.py calculate-ytm --mode buy --max-risk 2 --min-maturity 2026-01-01 --limit 10
```

## Методология расчета YTM

### Канонический cashflow-решатель
Доходность к погашению `y` определяется из уравнения равенства «грязной» цены (грязная цена = чистая цена `market_price` + НКД) приведенной стоимости будущих купонов и номинала:

$$\text{DirtyPrice} = \sum_{i=1}^n \frac{CF_i}{(1 + y/f)^{f \cdot t_i}}$$

где $f$ — частота выплат в год, $t_i$ — время до $i$-го денежного потока в годах.

### Обработка исключений (Intentional NULL)
Для инструментов, у которых денежный поток не детерминирован или график выплат отсутствует в БД, расчет YTM не подменяется упрощенными формулами текущей купонной доходности, а выставляет `NULL` со строгой причиной (`ytm_null_reason`):
- `floating_coupon` — облигации с плавающим купоном (будущие ставки неизвестны).
- `perpetual` — бессрочные облигации (нет даты погашения).
- `amortization_schedule_missing` — облигации с амортизацией до интеграции подробного графика погашений.
- `market_price_missing_or_nonpositive` — отсутствие или некорректная рыночная цена.

В табличном выводе CLI для таких инструментов отображается `— (<причина>)`.

## Хранение данных

- Поле `bonds_catalog.ytm` (`NUMERIC`): номинальная годовая доходность долей единицы (например, `0.152500`).
- Поле `bonds_catalog.ytm_null_reason` (`TEXT`): код причины, если расчет не применим.
- Поле `bonds_catalog.ytm_updated_at` (`TIMESTAMPTZ`): метка времени обновления.

## Устранение неполадок

### Проблема: Цены или YTM не рассчитаны
```bash
# Обновить рыночные цены через API
python3 main.py update-market-prices

# Или выполнить полный пересчет производных метрик (дюрация, YTM) в каталоге
python3 main.py update-bonds --recalculate-derived-metrics
```

### Проблема: Проверка схемы и миграций БД
```bash
python3 main.py migrate-db --status
```
