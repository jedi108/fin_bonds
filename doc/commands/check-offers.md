# Команда: `check-offers`

## Описание
Команда для проверки приближающихся оферт по облигациям в портфеле. Отслеживает даты оферт и отправляет уведомления о приближающихся событиях, помогая принимать решения о досрочном погашении.

## Синтаксис
```bash
python3 main.py check-offers [опции]
```

## Параметры

### Основные параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `--days` | integer | `30` | Количество дней для проверки оферт |
| `--notify` | flag | `true` | Отправлять уведомления |
| `--format` | string | `console` | Формат вывода |

### Детальное описание параметров

#### `--days`
Количество дней вперед для проверки оферт.

**Диапазон:** 1-365 дней
**Рекомендации:**
- Краткосрочные: `--days 7` (неделя)
- Среднесрочные: `--days 30` (месяц, по умолчанию)
- Долгосрочные: `--days 90` (квартал)

**Примеры:**
```bash
# Проверить оферты на следующую неделю
python3 main.py check-offers --days 7

# Проверить оферты на квартал
python3 main.py check-offers --days 90
```

#### `--notify`
Флаг для включения/отключения отправки уведомлений.

**Примеры:**
```bash
# Проверить оферты без уведомлений
python3 main.py check-offers --notify false

# Проверить оферты с уведомлениями (по умолчанию)
python3 main.py check-offers --notify true
```

#### `--format`
Формат вывода результатов.

**Доступные значения:**
- `console` - Вывод в консоль (по умолчанию)
- `csv` - CSV файл
- `telegram` - Только уведомления в Telegram

**Примеры:**
```bash
# Вывод в консоль
python3 main.py check-offers --format console

# Экспорт в CSV
python3 main.py check-offers --format csv --output offers.csv
```

## Алгоритм работы

### 1. Получение данных портфеля
1. Загружает позиции из `portfolio_positions`
2. Получает данные об облигациях из `bonds_catalog`
3. Фильтрует облигации с офертами

### 2. Анализ оферт
1. Проверяет даты оферт в указанном диапазоне
2. Вычисляет количество дней до оферты
3. Сравнивает цены оферты и текущие цены
4. Рассчитывает процентную разницу

### 3. Формирование отчета
1. Сортирует оферты по дате
2. Группирует по срочности
3. Формирует текст уведомлений
4. Подготавливает консольный вывод

### 4. Отправка уведомлений
1. Проверяет настройки уведомлений
2. Отправляет в Telegram (если включено)
3. Выводит отчет в консоль

## Ограничения и особенности

### Требования к данным
- Портфель должен быть синхронизирован
- Данные об офертах должны быть актуальными
- Рыночные цены должны быть обновлены

### Ограничения API
- Зависит от доступности Telegram API
- Ограничения на размер уведомлений
- Частота отправки уведомлений

### Производительность
- Время выполнения: ~10 секунд
- Память: Минимальная
- Сеть: Только для уведомлений

## Интеграция с другими командами

### Зависимости
- `sync-portfolio` - для актуальных данных портфеля
- `update-bonds` - для данных об офертах

### Использование результатов
Результаты используются для:

## Мониторинг и логирование

### Уровни логирования
- `INFO` - Основные этапы проверки
- `DEBUG` - Детальная информация об офертах
- `WARNING` - Проблемы с отдельными облигациями
- `ERROR` - Критические ошибки

### Ключевые метрики
- Количество найденных оферт
- Количество срочных оферт (<7 дней)
- Количество отправленных уведомлений
- Время выполнения проверки

## Устранение неполадок

### Проблема: Нет данных об офертах
```bash
# Проверить наличие данных об офертах
sqlite3 ratings.db "SELECT COUNT(*) FROM bonds_catalog WHERE offer_date IS NOT NULL;"

# Обновить данные с MOEX
python3 main.py update-bonds --source moex
```

### Проблема: Нет уведомлений
```bash
# Проверить настройки Telegram
cat config/config.yaml | grep telegram

# Проверить переменные окружения
echo $TELEGRAM_BOT_TOKEN
echo $TELEGRAM_CHAT_ID
```

### Проблема: Нет данных портфеля
```bash
# Проверить наличие позиций в портфеле
sqlite3 ratings.db "SELECT COUNT(*) FROM portfolio_positions;"

# Синхронизировать портфель
python3 main.py sync-portfolio
```

### Проблема: Некорректные даты
```bash
# Проверить данные об офертах
sqlite3 ratings.db "SELECT isin, name, offer_date FROM bonds_catalog WHERE offer_date IS NOT NULL LIMIT 5;"

# Проверить формат дат
sqlite3 ratings.db "SELECT isin, offer_date FROM bonds_catalog WHERE offer_date IS NOT NULL AND offer_date < '2020-01-01';"
```

## Стратегии принятия решений

### Когда продавать по оферте
- Текущая цена > Цена оферты
- Разница > 2-3%
- Альтернативные инвестиции с лучшей доходностью

### Когда оставлять облигацию
- Текущая цена < Цена оферты
- Разница < 1%
- Хорошая доходность к погашению

### Факторы для рассмотрения
- Налоговые последствия
- Комиссии брокера
- Альтернативные инвестиции
- Рыночные условия
